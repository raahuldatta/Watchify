# Watchify - AI-Powered Movie Recommendation App

A modern, full-stack movie recommendation application built with Next.js and AI-powered algorithms.

## 🎬 Features

- **AI-Powered Recommendations**: Get personalized movie suggestions based on your preferences
- **Modern UI**: Beautiful, responsive design with dark mode support
- **Multi-language Support**: Browse movies in multiple languages
- **Real-time Updates**: Live data from movie APIs
- **Advanced Search**: Filter by genre, language, and more

## 🚀 Tech Stack

- **Frontend**: Next.js 15, React 19, TypeScript
- **Styling**: Tailwind CSS, Framer Motion
- **UI Components**: Radix UI, shadcn/ui
- **State Management**: Redux Toolkit
- **APIs**: TMDb API, IMDB API

## 📋 Prerequisites

- Node.js 18+ 
- npm or yarn

## 🛠️ Installation

1. **Clone the repository**
   ```bash
   git clone <your-repo-url>
   cd watchify
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)
